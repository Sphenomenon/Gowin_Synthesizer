# 触摸板原理图复核 — 2026-10-13

依据：Schematic1.pdf（1页）、Netlist_Schematic1_2026-10-12.tel、Microchip AT42QT2160 9502C 数据手册、NXP PCA9685 Rev.4 数据手册、Worldsemi WS2812B-2427-V6 产品资料，以及已有板上诊断记录。本次只复核资料并修正文档，不改变RTL、SRAM或Flash。

## 判断

能确认一处控制说明错误、一处供电设计风险，以及一处型号/封装名称不一致。没有发现U1/U2采样外围拓扑、主要电源引脚或地址引脚的明确接错。原理图不能证明实物焊接、PCB连通、供电波形和电极布局都正确，也不能单独确定导致U2不应答或U1误报的唯一原因。

### 1. CHANGE 被错误解释为 CS — 确认的说明错误

原理图顶部第6条要求轮询前后主动拉低/拉高CHANGE，U1/U2说明也称它为CS。实际上CHANGE是低有效开漏输出，读完已变化的状态寄存器后由芯片释放。主机应读取，不应推挽驱动该线。U1/U2开漏输出共用CHANGE12及R3/R36上拉的连法本身可以成立。现有RTL已按输入处理，不能把这条错误说明当作当前故障的已确认原因。

手册依据：AT42QT2160 §5.5。

### 2. 触摸与LED共用电源 — 确认的设计风险，根因未证实

网表3V3同时供U1/U2、U3及经R47=0Ω供16颗RGB灯。图上第3条提出独立LDO，但实际电路未画出此隔离。QT2160以电源作为模拟参考，官方建议QT使用干净的独立稳压电源，不与LED负载共用；两颗QT可以共用一个稳压器。这能造成灵敏度变化或误触风险，但无法据此认定就是现有全键误报的原因，也不足以解释U2完全不ACK。

C1/C3各100nF的画法正确，是否靠近3/4脚要看PCB。手册明确：16/17脚供电走线足够短时不要求额外旁路，不能直接认定这里漏了电容。

RGB支路C12=100pF、C13=100nF；100pF不能承担储能作用。不过公共电源已有C9/C10各22µF，不能说整板没有储能电容。局部去耦、LED回流与QT电源回流需要结合PCB判断；100pF是否填错值也不能由原理图直接确定。

手册依据：AT42QT2160 §3.11、§3.10.2。

### 3. RGB灯型号与封装名称不一致 — 确认的资料不一致，实物错误未证实

PDF标注U5~U20为WS2812B-2427-V6；网表封装名却是LED-SMD_4P-L2.2-W2.0-P1.00_WS2815C-2020-4P。应核对实际采购型号、PCB焊盘尺寸/脚号及贴装方向。只有封装名称不足以证明实际焊盘错误。这一项主要针对灯链异常，不能直接解释QT的I²C不应答。

Worldsemi该V6型号产品资料列明支持3.3V供电，不能套用旧型号经验判定“3.3V必然错误”。前提是实物确为所标型号。

### 4. RST固定接3V3 — 合法，但不利于故障恢复

U1/U2.25直接接3V3，手册允许。缺点是FPGA没有独立硬复位控制：U2不ACK时无法通过I²C软复位，也不能由FPGA拉RST恢复。下一版宜预留复位控制/测试点。这是可维护性不足，不是必须改才能工作的硬错误。

手册依据：AT42QT2160 §3.14。

## 已核对且没有明显问题的部分

- U1/U2主要供电和地脚、VREF.8接地、EP.29接地，符合引脚定义。
- U1两组Cs=C7/C8，U2一组Cs=C11，均4.7nF；YB经1MΩ接SMP；X/Y串1kΩ，符合典型电路。电容介质/容差未在本图明确，手册建议10% X7R。
- U1的8X×2Y可以构成16键；U2的8X×1Y滑条合法，未使用的Y1A/Y1B应悬空。
- 两颗QT地址均0x0D但使用独立总线，不构成地址冲突。
- U3 PCA9685的SCL.26、SDA.27、A0~A5接地、EXTCLK接地及OE接地符合手册，7位地址0x40正确。

## 与现有板上证据的对应关系

- 已有完整GPIO配对/地址扫描仅发现U1；U2/U3均未响应。不能仅以电极参数或阈值解释U2无ACK。
- U2/U3的四根I²C线均经过RN1，因此RN1及连接/焊接是优先检查对象，但不是已确定坏件。
- U2 SDA：U4.4 → RN1.8/1 → U2.23；SCL：U4.6 → RN1.7/2 → U2.24。电阻两端跨100Ω。
- U3 SDA：U4.10 → RN1.5/4 → U3.27，上拉为R20=4.7kΩ；SCL：U4.8 → RN1.6/3 → U3.26，上拉为R21=4.7kΩ。
- 撤去FPGA内部上拉后，SDA3释放1ms未回高，与所画R20上拉通路的正常状态不符。可能是上拉/通路开路、短路或器件持续拉低，现有证据不能区分。先前报告将SDA3上拉误记成R21，已同步改为R20。
- U1现有读数含0和接近2000的值，且无触摸全键误报；如果这些原始值正确，明显偏离手册建议200~750的常用信号范围。应优先关注共同采样节点、Rs/Cs实际装配、供电、PCB寄生耦合，并保留读取完整性的可能；不能仅据数字值宣称模拟端已饱和。

优先级：先查U2供电/复位与RN1两条总线通路、U3 SDA3/R20低电平问题；再查U1模拟采样和供电；灯型号/封装与灯链单独核对。不要把提高触摸阈值当成硬件已修复。
