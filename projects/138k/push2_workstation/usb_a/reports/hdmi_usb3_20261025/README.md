### DDC 对应关系更正

此前对话把 U7 两路的内部对应关系写反，纠正在此，TMDS 八根连接不变。补充的 2026-10-16 EPro 工程中，U7 的 Device 元数据是 `TXS0102DCTR`；实际装配型号仍须核对。TI `TXS0102` SCES640L（2026-01）第 3 页 DCT 管脚表规定 `B1=8 ↔ A1=5`、`B2=1 ↔ A2=4`，不是按管脚数字顺序配对。结合 2026-10-21 网表，应为：

- SCL：`USB3.15 → U7.8(B1) ↔ U7.5(A1) → J2.85 → M13`。
- SDA：`USB3.16 → U7.1(B2) ↔ U7.4(A2) → J2.84 → L13`。

U7.3 是 VCCA、U7.6 是 OE，均接 `3V3_VP`；U7.7 是 VCCB，接 `+5V_DVI`。当前彩条顶层没有驱动 DDC 或读取 EDID，故这个管脚说明更正不是已确认的无信号根因，也不需要因此重综合或重新烧写当前诊断。
