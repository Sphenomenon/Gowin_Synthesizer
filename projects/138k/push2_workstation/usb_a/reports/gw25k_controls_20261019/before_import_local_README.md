# 25K 面板工程

这是与 [138K 主机](../138k/README.md) 同级的设备端工程目录。目前本机仓库只有 138K Host 适配、PL 规范和历史验证记录，尚未导入完整 25K 工程。本目录不提供可综合顶层或板级构建入口。

25K 连接触摸板和 SPI 屏，将触摸转为 MIDI，处理本地移调并驱动外围。现阶段通过 138K 板载 USB-A 与 Push 轮流接入，自动识别。Push 直接连接 138K；曲谱跟奏为 Push 专有。

对接依据：

- [整机接口规划](../../整机接口规划.md)：已确认的触摸键、滑条、编码器映射，初始化和功能边界。
- [现有 PL 规范](../138k/push2_workstation/usb_a/GW25K_PANEL.md)：USB 端点、包格式、会话、序号、重试、心跳和 MMIO。该历史规范中的 25K 跟奏候选与当前产品范围存在差异，以整机规划的差异说明对接。
- [138K Host 固件](../138k/push2_workstation/usb_a/firmware.c)与 [PL 显示服务](../138k/push2_workstation/usb_a/gw25k_panel.h)：当前主机侧实现，不是 25K 设备端源码。

导入完整工程前需核对原始工程路径、版本和许可，以及板型、时钟、SPI 屏控制器与连线、实际电极键序。设备端音量／音色同步和已确认控件映射仍待在实际源码中接入；移调入口、范围与越界行为另行确定。当前不新增菜单、长按功能或 25K 专有入口。

收到源码后在本目录保留原始相对结构，并补充来源清单和实际构建命令。板级构建产物放在本目录的 `results/`，由统一忽略规则排除。未经实际验收，不把接口规划写成设备端实现或板测结果。


2026-10-19复核：本目录仍只有本说明；在本机用户目录按`panel_display_endpoint.v`和25K工程文件名检索，未找到完整设备工程。138K基础页已明确区分有效GAIN、音色名称、已提交模式、BEND IDX和实际效果位；这不等于25K本地控件同步已实现，也不提供本地移调反馈。验证与来源边界见[功能优先续验](../138k/push2_workstation/usb_a/reports/FUNCTION_FIRST_20261019.md)。


2026-10-19功能方向补充：用户已明确25K专有交互借鉴K.O.II／EP-133，4×4键在演奏与效果上下文中复用，已有声音播放时可开关并组合效果，并要求借鉴不违反题目要求的其他工作流。采样／效果计算仍归138K。当前仅有独立D后端及三项效果组合验证，旧Push 8×8映射不能直接套用25K，完整设备端和整机路由尚未接通。具体上下文入口、16键表和触发方式待定。详见[现场演奏目标与验证](../138k/push2_workstation/usb_a/reports/GW25K_PERFORMANCE_SCOPE_20261019.md)。


2026-10-19题目补充：用户确认D采样器／TF PCM可作为实时发声技术路径，禁止直接播放预处理音乐；保留既有采样、切片、变调和组合效果基础，不因PCM格式一概排除。音频生成与效果仍在138K，25K负责自研交互与外围。题目≥2维自研交互、拓展表达维度、传感器到模拟音频延迟和实际I2S格式仍需按[赛题验收对照](../138k/push2_workstation/usb_a/reports/CONTEST_REQUIREMENTS_20261019.md)取得整机证据；当前32音频谱测试通过不代表设备端完成。
