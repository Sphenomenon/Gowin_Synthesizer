2. Pitch Bend8192、CC64=0、CC11=127、CC1=0、CC5=0、CC82=0。

## 兼容边界

`GW25K_PANEL.md`原文未改。USB端点、PL包、会话、序号、重试、心跳、manual兼容及既有指令含义保持。MIDI OUT01端点保留，本批25K不发送曲谱引导回传。Push物理CC经自身映射层消费，不与D逻辑CC20／21／22直接混用。

138K内部0x00寄存器保留bit0连接、bit1 generic，新增原保留bit2作为完整识别的GW25K资格位：Push写1、普通generic写3、GW25K写7、断开写0。生产Host固件和控制RTL须配套更新；旧固件写3无法启用25K功能隔离。0x24、0x5c、0x60／64／68／6c等原字段未改；0x3c映射诊断计数保持累计，不随Push本地状态清空而归零。

片上18 bit `{kind,a,b}`普通事件不变。内部kind15只用于生命周期：b0断开、b1接入且a[0]决定是否执行公共默认、b2紧急PANIC、b3等待初始化完成。不将其定义为USB／PL命令。普通generic接入不应用Push／GW25K公共默认；已有曲谱行为保留。

当前事件没有来源标签，USB边界仍全局PANIC，外层／内层各一个已受理暂存项可能一同作废；其他输入解析器保留。此批不提供多来源独立清音保证。PL会话单独恢复沿用原规则，不触发USB接入默认值。

## 复现

在`projects/138k/push2_workstation/usb_a`执行，均不访问板卡：

```sh
python3 sim/run_workstation_attach.py
python3 sim/run_pl_guide.py
python3 sim/run_gw25k_panel.py
python3 sim/sampler/run.py --test tb_sampler_controls
python3 sim/sampler/run.py --test tb_sampler_mode_d
python3 build.py --prepare-only --no-update-latest
```
