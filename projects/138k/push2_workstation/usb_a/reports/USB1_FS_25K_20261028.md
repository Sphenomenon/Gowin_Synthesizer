# 138K USB1 ↔ 25K Full-Speed 识别、模块与综合

日期：2026-10-28。状态：**源实现、离线仿真和两板综合通过；未 P&R、未生成位流、未操作板卡。**

## 交付范围

- 138K：独立 USB1 FS Host/识别候选，使用原生 RV32I/总线、锁定 FS MAC/PHY 和生产 MIDI/PL 固件。发布设备身份、枚举/PL 就绪状态、事件计数和 UART 诊断。
- 25K：同一 `midi_keyboard_top` 的显式 USB1 FS 配置，保留演奏控件、触摸、BLE、灯光、LCD、MK/PL，替换 USB3300/ULPI 为 D+/D− 软 PHY 和 48 MHz PLLA。
- MIDI 与 PL 复用既有线规，没有新增私有握手、消息编号或参数权威副本。18-bit 事件布局及既有 PANIC/生命周期定义不变。
- **138K 本次独立 top 不含音频、DDR、HDMI、CNN，也未接回完整工作站 owner/音频链。** 它不是新的完整工作站发布，不能由本报告推断板上已发声、屏幕已显示或 USB1 完整业务已验收。
- 默认 USB2、accepted full83、timing85、resource-timing、当前板上 SRAM/Flash 和部署索引没有切换。接手时已有的 USB2/ULPI/HDMI 等工作区内容保留。

实现与复现入口：[主机模块/构建说明](../rtl/usb1/README.md)、[25K USB1 配置与协议边界](../../../../25k/example/MIDI_KEYBOARD/docs/USB1_FS.md)。

## 识别链路

1. 138K USB1 attach → 根复位 → 标准描述符/地址/配置。
2. 生产 Host 按合法 MIDIStreaming 1.0 描述符选择 Bulk IN；不凭 VID/PID 就判成面板。
3. 本地 `FB9A:FB9B` 还需 MIDI OUT 和接口 2 的独立 vendor Bulk IN/OUT，才标记 25K 分支。
4. 原 PL local-v1 HELLO/CAPS 校验成功，才发布 PL ready；端点枚举完成与 PL 就绪分别可见。

FS EP0 和四个 Bulk 方向均为 64 字节。25K FS-only 不发送 HS chirp，对双速专用 Device Qualifier/Other-Speed Configuration 请求 STALL。默认 USB2 仍使用原双速路径和描述符 ROM。

取消与故障行为：连续 SE0 约 1 ms 清除主机诊断会话；短 EOP 不清。被背压的旧事件及旧身份/PL-ready 不能在快速重插后重新变为有效。原生产软件 50 ms 无回复重枚举保留。服务消费者仍受既有 10 ms 总线 watchdog 约束，超时通过 fault 显式报告；后续音频整机接入必须继续走原 owner、会话/PANIC 和参数提交边界，不能把诊断 MMIO ACK 当成音频执行。

## 接线和未关闭的物理门禁

锁定新底板网表 USB1 的 D+ 经 R33 到 H13，D− 经 R34 到 G13；25K USB1 为 L6/K6。USB2/USB3300 不是本批通道，网表 `USB3` 是 HDMI。

**Host 角色必须先查实板：**

- 网表 R1/R2 把 USB1 的 CC1/CC2 以 5.1 kΩ 接地，是 sink Rd 接法，不是已验证的 Type-C Host Rp。不能仅用 C-C 线就推断角色成立。
- VBUS1 经 F1 直接连板上 +5V，没有 FPGA 控制的供电开关；两板供电、线缆/转接与防反灌仍需实测，不授权自行换阻值或改变供电。
- 138K Host 侧 R37(NC) 可选 D+ 1.5 kΩ 上拉应不装；25K Device 侧必须有物理 D+ 1.5 kΩ 上拉。RTL 不以弱上拉或驱高 GPIO 替代它。
- 没有 P&R、routed timing/CDC/PLL、实际 Bank 电压/USB 波形、硬件枚举或断电重启记录。`deployment_allowed=false` 保持；SRAM 和 Flash 均需另外明确授权和独立身份读回/验收。

## 回退

本批没有部署，无需恢复板卡。代码/构建回退为不选择 `--usb1-identify`，25K 默认仍运行原 USB2 profile；已接受的整机源策略和历史位流没有替换。不要拿本批纯识别候选覆盖现有整机，再把音频/显示缺失误当成业务回归。

后续若进入完整 138K 工作站，需显式选择 USB1 owner 组合、连接原音频会话和公共参数、重跑整机功能/资源/CDC/PLL/时序，再单独请求板卡操作授权。本报告不提前宣称这些阶段完成。
