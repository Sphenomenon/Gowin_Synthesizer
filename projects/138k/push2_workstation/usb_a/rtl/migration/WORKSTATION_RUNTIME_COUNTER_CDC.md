# Native runtime counter CDC

`workstation_runtime_counter_cdc.sv` keeps the locked `gw138k_counter_cdc` interface, registered source Gray word, two destination synchronizer stages and both local three-edge reset releases. Only the local combinational Gray-to-binary decode changes: five parallel-prefix XOR stages replace the 31-level serial recurrence. No destination clock of latency is added. Source counts still must change by at most one per source edge, and the existing per-bit flight constraints still apply.

All explicit native runtime workstation profiles select this versioned source through `workstation_runtime_profile.SOURCES` and `REPLACEMENTS`. Their prepared projects preserve the original parent `src/migration/gw138k_counter_cdc.sv` bytes but disable its compilation entry. Native source SHA, disabled parent SHA and replacement/copy/compiled ownership are recorded in `runtime_audio.counter_cdc`. No text-generated RTL is used. Unprofiled new-board preparation, accepted full83, pinned timing85 and the resource parent retain their original input choices.

`tools/workstation_runtime_counter.py` resolves the actual enabled owner from GPRJ, integration metadata and the prepared profile. New native selection requires all ownership/hash links to agree and fails if the new source is missing. Old serial candidates remain explicitly identifiable; the presence of a disabled staged old file never makes it the current implementation. Existing register and instance names remain so the original endpoint contracts are not redefined. An actual new VG still needs its own source/CDC/timing review; old pinned-serial evidence is not inherited.

`sim/cdc/run_runtime_counter_cdc.py` proves the exact native combinational equations as a GF(2) matrix for all2^32 input values and verifies an unchanged sequential token boundary. Each suffix variable occurs once, supporting four-state XOR reassociation as well. Directed asynchronous comparisons cover local release, final published count with stopped source, stopped destination, common reset while both clocks stop and wrap. These digital checks do not model metastability resolution or routed delay.

The observation, display, controlled runtime and memory/TF integration source lists use the same explicit source resolver. A new candidate must record the selected native source; retained old serial staging and old acceptance remain separate. Source XOR depth is five, but physical mapping, resource cost, setup/hold, reset recovery/removal and hardware acceptance require separate new-candidate evidence.
