## 基频与 P25 窗纪律

用两通道 circle 的 `unwrap(atan2(Y,X))` 对 8192 个稳态样本拟合相位斜率，另列出 32-bit 相位步进的理论量化频率。FFT 采用周期 Hann：`0.5−0.5 cos(2πn/N)`，N=2048，基频中心 ±2 bins 外最大值为远端峰值；DC 的前三个 bins 排除。

| 音符 | 目标 Hz | 步进量化 Hz | 实测 Hz | 实测误差 Hz | 最大远端 dBc | ±2 bins 外功率 dB |
|---|---:|---:|---:|---:|---:|---:|
| MIDI 69 | 440.000000000 | 440.000005066 | 440.000004067 | +0.000004067 | −38.724 | −38.579 |
| MIDI 60 | 261.625565301 | 261.625561863 | 261.625561605 | −0.000003696 | −42.028 | −41.357 |

MIDI 60 的远端峰值与 P25 的约 −42.02 dBc 一致。440 Hz 在 2048 点 FFT 中的分数 bin 位置不同，Hann 远端峰值约 −38.72 dBc；没有把不同音符的窗旁瓣强行写成统一 −42 dBc。X/Y 圆轨迹相关系数接近零，左右相位方向与坐标顺序正确。

## 防混叠前后：真实 HDL 输出

TB 同时实例化相同的 HDL 引擎：一份读取生产平滑路径，另一份读取**未平滑方形几何**。两者采用相同相位、ADSR、力度与线性插值，逐帧 valid 对齐。测试用原始路径仍是几何坐标 ROM，不是音频样本输入。N=8192 周期 Hann，参考幅度为基频附近峰值。

| 扫描音高 | 原始第 13 次谐波／折叠峰 dBc | 平滑后同频峰 dBc | 抑制 dB |
|---|---:|---:|---:|
| 440 Hz | −44.755 | −108.461 | 63.706 |
| MIDI 95，1975.53 Hz | −44.425 | −107.324 | 62.898 |

440 Hz 的第 13 次谐波为 5720 Hz，仍在 Nyquist 内，此组证明超出编译器 8 次谐波上限的成分被移除。MIDI 95 的第 13 次谐波约 25681.9 Hz，折叠到约 22318.1 Hz，此组直接量化混叠抑制。没有把前一组的 5720 Hz 称作混叠。

排除前 8 次谐波中心 ±2 bins 后，方形路径最大远端峰值：440 Hz 原始 −38.267、平滑 −47.385 dBc；MIDI 95 原始 −39.029、平滑 −42.337 dBc。这个宽泛指标仍受 Hann 旁瓣影响，不能作为所有 alias 分量的幅度。16-bit 坐标量化和线性插值的残余镜像没有被宣称为零。

生产边界固定扫描率 ≤2000 Hz、8 次谐波 ≤16 kHz。测试明确拒绝 MIDI 96，弯音后的越界扫描置错误并输出零帧，恢复合法频率可继续发声。220…659.57 Hz 的连续 Q20 扫描变化通过。

## 包络、morph 与切换沿

独立 TB 采用测试 ADSR 控制表加速状态覆盖，生产 ROM 仍读取原五个 Q24 profile。断言验证：64 帧线性 attack 到 `0xffffff`；32 帧 decay 到 `0x800000`；sustain 稳定；32 帧 release 到 idle；0 步进的原“立即到目标”语义也通过。生产 ADSR 由完整工作站 TB 实例使用。

同一 MIDI 69 从 circle morph 到 figure-eight 后，X 的主频保持 440 Hz、Y 变为 880 Hz。morph 满程必须到 Q15 32768，旋转 90° 必须到内部第 128/512 圈位置。

| 操作 | 最大相邻样本变化（满幅比例，L/R 取较大） | 断言上限 |
|---|---:|---:|
| morph | 0.013165 | 0.018 |
| 旋转 | 0.014698 | 0.018 |
| mute | 0.012302 | 0.018 |
| unmute | 0.013165 | 0.018 |
| release | 0.010490 | 0.018 |

这些是单 voice、MIDI 69、约 1/8 满幅、受控渐变的数字连续性证据，包含原振荡波形自身的正常相邻样本差分，不能替代模拟耳机的爆音听测，也没有宣称所有音高、8 voice 满幅或 PANIC 硬截断都满足同一门限。mute 和 release 尾部为逐位零；PANIC 后独立引擎、工作站和效果链均无持续残留。

通道校准用稳态块的正弦／余弦／DC 联合拟合，避免非整数周期均值偏差：X 设置 1.25、测得 1.249998765；Y 设置 0.75、测得 0.750000358。偏移设置 ±0.000488281 满幅，拟合分别为 +0.000482198 与 −0.000491900，误差小于 0.00002。PT8211 实际模拟误差尚未测量。

本次 SYN 音频域实际估计 49.599 MHz，约束为 76.8 MHz，首条最差路径 slack −7.141 ns：原 `engine/final_accumulator_3_s1` → `engine/quantized_mix_37_s1`。没有重构原合成器来规避这个限制。USB 域也保留综合估计的低 Fmax；这些估计不等于实际 routed slack。

所以本阶段结论是**离线源码、功能与资源检查通过**。尚未验收：P&R 76.8 MHz 时序、DAC 模拟 L/R 校准、听觉爆音、真实 HDMI 图形、实体控制延迟。专用 scope 状态仍在冻结 wrapper 留空；详细 MMIO 镜像未新增。没有调用 programmer、SRAM/Flash 操作、板卡探测或 UserCode 分配；未写 Git commit。
