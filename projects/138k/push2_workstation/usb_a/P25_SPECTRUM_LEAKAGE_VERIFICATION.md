# P25 频谱泄露受控实验验证

2026-09-16 在已验收 P24 源码和最终 PCM 上完成。正式实验目录为 `push2_workstation/results/p25_spectrum_leakage_20260916_184000_550894`，总结果 `experiment.json` SHA256 为 `c568a75de38923e3ff4c84b5afb5ffa8f912e7595ccfece0fee66d2c237d8e8c`；对比图 `spectrum_factors.png` SHA256 为 `fe7599cd50fb28d2c0f04c505a979aa7b2366bac7e34c14cedbd25261deec44f`。

## 分项结果

同一 261.6256 Hz 单正弦、N=2048 时：

| 窗 | ±2 bins 外功率 | 最大远端 bin | 约 −84 dBc 内可见 bins |
|---|---:|---:|---:|
| 矩形 | −17.11 dB | −24.24 dBc | 852 |
| 当前周期 Hann | −41.36 dB | −42.02 dBc | 23 |

周期 Hann 将最大远端 bin 再压低 17.78 dB、±2 bins 外总功率再压低 24.25 dB，当前窗不是异常来源，也不应换回矩形窗。64 个起始相位中，最大远端 bin 只在 −42.039…−42.017 dBc 之间变化，跨度 0.022 dB；稳态频谱泄露不由任意捕获起始相位主导。

把同一个 FFT 幅度数组按 48 kHz 或旧 48.828125 kHz 标记，所有幅度 bin 位对位相同，只是 bin 11 的标签从 257.8125 Hz 变成 262.2604 Hz。生产时钟、scheduler、合成参数、FFT ROM 和显示标注均使用 48 kHz，采样率错误被排除为幅度铺展原因。

| N | bin 间距 | Hann 主瓣零点间宽度 | MIDI 60 分数 bin 偏移 | 最大远端 bin |
|---:|---:|---:|---:|---:|
| 512 | 93.750 Hz | 375.000 Hz | −0.209 | −43.36 dBc |
| 1024 | 46.875 Hz | 187.500 Hz | −0.419 | −32.36 dBc |
| 2048 | 23.438 Hz | 93.750 Hz | +0.163 | −42.02 dBc |
| 4096 | 11.719 Hz | 46.875 Hz | +0.325 | −35.05 dBc |
| 8192 | 5.859 Hz | 23.438 Hz | −0.349 | −34.34 dBc |

增大 N 会按比例缩窄 Hz 主瓣、改善频率分辨率，但音符在不同 N 下落到不同分数 bin，相对旁瓣不会单调下降。当前 2048 点不是点数太小导致的算法错误；是否用更长块属于显示分辨率、延迟和 BSRAM 的独立权衡，本轮不修改。

P24 十五组 A/B/C × 五音色最终 DAC PCM 中，既有 32 个整数谐波的 Hann 主瓣解释 99.9598%…99.9926% 的总功率。B/C 尤其会显示很多真实高次谐波，不能把这些离散线当成 FFT 泄露。当前显示约 84.3 dB 的范围也会让低电平 Hann 旁瓣可见。

## PANIC 与 RTL 对照

`tb_panic_spectrum.sv` 使用 P24 的真实 allocator、振荡器和三段串行效果链，先填充效果历史，再发 CC120。PANIC 后左右各记录 4096 点，非零样本均为 0。把 PANIC 前样本与零拼成一个跨界 2048 点块时会出现宽带谱：一半旧声音加一半零时最大远端约 −12.25 dBc；第一个完全位于 PANIC 后的 2048 点块全零。结论是 PANIC 不留持续音频残余，但捕获不清 bank，因此最多出现一个硬截断过渡块，之后显示还可能等到下一帧边界发布。

当前 P24 阶段源另通过 `gw138k_audio/results/bar_analysis_20260916_184022_907051`：九组双声道/静音/反相/满幅/弱信号/高频 PCM 仿真通过，左右共 4096 个复数 bin 与独立直接 DFT 对照通过，最大误差 6.757 guard units，限制为 64。该 `verification.json` SHA256 为 `30a14099c4ba3a40a00fba208059e7619b05403cc838552e6e5f453c5c096e1a`。

## 版本状态

本实验没有发现需要修正的生产 RTL，因而没有制造内容等同却更换 UserCode 的 P25 位流，也没有执行 SRAM 或 Flash 操作。板上继续运行已实体验收的 P24 `0x00000024`；P24 位流 SHA256 仍为 `7a37311de6df38ed1f0191bd2f07094904df826dd69c4b2007f2e0ec099c1c66`。本轮没有完整 P&R，不能声称旧 routed audit 通过；原三个 `effect_mask_sync` reset 缺口仍保留，USB IN error 仍为 `null`。
