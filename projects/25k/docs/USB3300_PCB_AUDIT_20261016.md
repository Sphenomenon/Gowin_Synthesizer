## 已证实的设计偏差：数字1.8V稳压器缺少4.7uF

USB3300 官方 DS00001783C §3.2 Table 3-1 pin26 明确要求：启用内部稳压器时在此引脚旁放4.7uF low-ESR到地；§6.4.1进一步说明两个1.8V内部稳压器各需4.7uF ±20% low-ESR以保证稳定性，建议X5R/X7R。参考文本 `/private/tmp/usb3300_official.txt` 629–634、2372–2376行。

PCB VDD18 网络的所有 PAD_NET 记录穷举仅以下四项：

| 引脚 | 源记录行 | 设计值 |
| --- | ---: | --- |
| C13.1 | 6917 | 100nF |
| C14.1 | 6923 | 100nF |
| U2.15 | 7367 | 数字1.8V |
| U2.26 | 7378 | 数字1.8V稳压输出 |

C13/C14组件无Value覆写，继承Device `8a8a49af6ac26752`，该Device META在3212行明记Value=100nF。
VDD18全部实铜线、焊盘、过孔形成同一个连通分量，电容没有落在别的独立孤网。无额外4.7uF焊盘接此网。

模拟VDDA1.8是不同网络 `$1N107`，仅C11.1(6905)、C12.1(6911)、U2.29(7381)；C11组件6903行Value=4.7uF，C12继承100nF。实铜也形成一个连通分量。**C11不为数字VDD18补偿电容**，两路内部稳压输出不能在启用时相连。

这是原生PCB与官方必需条件之间的确定设计差异。**无法仅凭它证明当前FS/LS LineState=11或不枚举就是由此造成**；实际稳定性/修复后枚举仍需实物验证。

## DP/DM实铜与足印

- USB2.A6、B6同属 `$1N25`，经R7.1；R7.2属USB2_HS_DP，接U2.7。
- USB2.A7、B7同属 `$1N26`，经R8.1；R8.2属USB2_HS_DM，接U2.8。
- R7/R8分别7164/7170行，Value均0R。连接器PAD_NET在7531–7534行；U2.7/8在7359–7360行。
- 按实际铜形计算以上四段网络各自都连通，不只检查网名。DM在连接器后有两颗通孔换到底层，再穿过DP顶层走线；跨层处不会自动相连。
- 显式LINE+VIA+足印PAD中，DP与DM铜间隙最小5.9843mil=0.152001mm，发生在顶层DP线7730行与DM过孔7739/7740行。没有相交/零间距；与其他显式不同网铜也没有相交。
- 当前仍有对应POUR实体的POURED数据均纳入辅助检查；顶/底GND填充未与USB铜相交，最近间隙约14.0994mil。弧线离散化弓高误差上限0.0005mil。该自写几何检查不等价于立创官方DRC或生产Gerber检查。
- USB3300足印 `90bf9fc189c5bdfc` 为标准四边各8脚、0.5mm pitch的顺序32脚QFN加中心33地焊盘；7/8相邻（747/748行）。U2为Top layer、rotation180°，没有镜像设置。变换后U2.7坐标(2570.3752,1122.1408)，U2.8=(2550.6952,1122.1408)，对应DP/DM出线终点。官方定义7=DP、8=DM（文本481–490行），没有发现库内7/8交换。
- 连接器足印 `b1ae1bdaedc7b740` 标注TYPEC-16P，A6/B6与A7/B7的分配符合其自身库定义。原工程可证明该库按既定编号连线，**不能仅凭库内自洽排除实装Type-C料号与库不匹配，或焊接镜像/短路**；实装料号/厂家引脚图和实际焊接状态没有独立证据。

## RBIAS和地

- U2.32(7384行)经`$1N87`实铜连接R10.1(7184行)，R10.2到GND。
- R10组件7182行明确覆写Value=12K，符合官方12k标称值；未指定精度，**设计数据不能证明±1%或实装12k**。
- 中心EP33接GND（7352行）；EP范围内原生PCB有3颗GND过孔：8289, 8290, 8981行。符合通过阵列接地的结构意图；实焊/地阻抗未测。
