## 3. 汇总存在的问题及具体修订意见

### 3.1 上电前优先：USB3300 数字 1.8V 稳压输出缺少规定电容

原汇总第 3.1、5.2 节及附录 A 正确记录：

- U2.31 `REG_EN` 接 `USB_3V3`，启用内部稳压器。
- U2.15 / U2.26 共接数字 `VDD18`，只有 C13、C14 各 `100nF` 到地。
- U2.29 是另一条模拟 `VDDA1.8` 网络，配置 C11=`4.7µF`、C12=`100nF`。

但原汇总没有指出：**数字 `VDD18` 缺少手册要求的 4.7µF 低 ESR 稳压输出电容。** 两只 100nF 不能代替这个要求。

[Microchip USB3300 官方手册 DS00001783C](https://ww1.microchip.com/downloads/en/DeviceDoc/00001783C.pdf) 第 9 页表 3-1（26 脚）要求在此脚附近接 4.7µF 低 ESR 电容到地；第 35 页 §6.4.1 进一步说明两个内部稳压器各需要 4.7µF、±20% 的低 ESR 电容保证稳定，推荐 X5R/X7R。

**处理建议：** 先核对实板 C13/C14 和补焊情况。若与图纸一致，应在数字 `VDD18` 侧补齐规定的电容并保留所需高频去耦，安装位置应靠近 U2.26。具体补焊位置需结合 PCB 实物确定。

模拟侧 C11 已属于另一稳压输出，不能替代数字侧电容。内部稳压器启用时，手册要求数字 `VDD1.8` 与模拟 `VDDA1.8` 分开，**不能通过合并这两网来共用 C11**；也不能把它们接到底板 `VDD_1V8`。

这里确定的是图纸标称配置不满足电容要求；实板是否已改料，仍需装配记录或实物确认。

### 3.2 已关闭：原图 1.8V BANK2 与 USB3300 的 ULPI 电平问题

**最新状态：用户已确认所有 BANK 后期全部改为 3.3V。因此，原先针对 1.8V BANK2 的输入高电平不匹配问题已关闭。** 后续设计按当前 3.3V BANK 电平选择匹配的 FPGA I/O 标准；本条关闭不等同于 ULPI 时序或本板 USB 功能已经测试通过。

原汇总第 3.2、5.2、7 节已记录全部 12 根 ULPI 信号接 BANK2、图注 BANK2 为 1.8V、没有电平转换器；原文只把兼容性作为待查事项。

官方手册第 12 页表 5-3 给出 USB3300 数字逻辑脚规格：

| 参数 | 保证值 |
| --- | --- |
| 输入高电平 `VIH` | 最低 2.0V |
| 输入低电平 `VIL` | 最高 0.8V |
| 输出高电平 `VOH` | 最低 `VDD3.3 − 0.4V`，条件 `IOH = −8mA`；3.3V 供电时为 2.9V |
| 输出低电平 `VOL` | 最高 0.4V，条件 `IOL = 8mA` |

**改版前图纸的问题是：1.8V BANK2 的 FPGA 输出高电平不能满足 USB3300 的 2.0V 最低输入高门限。** 此判断保留为修改背景，不再作为当前 3.3V 实板的未解决问题。USB3300 内部 `VDD18` / `VDDA1.8` 仍为 1.8V 稳压输出，不随 BANK 改为 3.3V；第 3.1 节的稳压输出电容要求仍然有效。

用户确认的是 BANK 的当前电平，不能据此推断核心板独立 `VDD_1V8` 电源本身也改为 3.3V，或原图中的电源合网关系仍完整适用于改后实板；具体改线应在后续修订图中记录。

补充核对 [Sipeed 官方 Tang Primer 25K 52300 核心板原理图](https://dl.sipeed.com/fileList/TANG/Primer_25K/02_Schematic/Tang_Primer_25K_52300_Schematic.pdf) 第 2、5 页：`VCCIO2/3` 单独引到板对板连接器，核心板未在图中将它硬接至 1.8V；本项目原始底板工程通过 Short-Symbol 将它连接到 `VDD_1V8`。因此，原图中的 1.8V 是改版前底板连接所确定的配置，不能理解为该核心板所有使用场景都固定为 1.8V。

### 3.3 可以关闭：USB3300 RESET 接地并非复位接错

原汇总第 5.2、7 节将 RESET 极性留待确认；官方手册已经能回答：

- 第 8 页表 3-1：U2.9 RESET 为可选的**高有效**收发器复位，不使用时推荐接地。
- 此引脚等价于 ULPI `04h` 的复位位，不复位整个 ULPI 寄存器组。
- 第 35 页 §6.4.2：芯片有内部 POR；3.3V 断电重上可将寄存器恢复默认值，运行中也可逐项写回默认值。

建议原汇总改为：“RESET 接地符合未使用可选复位脚的推荐接法；本板没有 FPGA 控制的独立 RESET 线，需区分收发器复位与完整寄存器上电复位。”复位极性不需要用户回答。

### 3.4 表述微调：PATCH_BYTES 不是公共顶层的可调参数

原汇总第 6.2 节把 `PATCH_BYTES=30147` 放在“参数”表中，容易使人理解为能直接在 `rtl8723ds_ble` 顶层覆盖。

实际公共顶层暴露 `CLK_HZ`、`DISABLE_MS`、`STARTUP_MS`、`SESSION_MS`、`NOTIFY_MS`、`PATCH_FILE`，在内部固定传入 `BAUD=115200` 和 `PATCH_BYTES=30147`。建议把该行标为“固定补丁长度：30147 字节，非公共顶层参数”。

还可补充两个功能边界：H5 数据 CRC 关闭，测试通知自身另带 CRC；当前不支持 ACL 分片。以上属于资料可直接确认的事实，无需用户裁决。

## 4. 原汇总中应保留的问题

| 项目 | 复核意见及处理时机 |
| --- | --- |
| 两个 USB 口共电源 | VBUS 与 J2 的 +5V 直接共网，没有隔离或择源。首轮调试先只用一个 5V 输入来源；决定双口用途或增加外部供电前，再确定电源路径和角色管理 |
| USB 角色 | 两口 CC 均为 5.1K 下拉，USB3300 的 CPEN/ID 未使用。当前连接不证明已有完整 Host/OTG 方案；用户已回复用途未定，后续功能规划时再选择 |
| USB1 全速 | FPGA 直连、没有独立 PHY/明确独立 1.5K D+ 上拉；名称本身不能证明已具备可枚举的 USB 实现 |
| L1 单位 | 电感符号/封装，但 SCH、PCB 的 Value 都写 `2.2nF`。确定存在属性单位异常，不能擅自改为 2.2nH；需实际物料/装配值 |
| 天线装配 | RF1 陶瓷天线与 RF2 IPEX 共网，图注要求二选一；需确认实装选择及外接天线情况 |
| LCD | RST 固定高、没有独立背光 PWM 是功能限制，不足以证明屏幕不能初始化；无独立 MISO 也不能直接推出 SDA 不支持双向读回。需具体模组资料判断 |
| 触摸/弹拨子板 | 目前只有连接器与网名；不能由 SDA/SCL、IO、PWM 名字推导完整协议、电平或负载 |
| BLE 集成 | 包内实现默认发固定测试通知、180 秒后释放输出；没有任意业务数据输入。释放输出后 BT_DIS# 仍被 R20 上拉，不等于关闭射频。业务用途、持续运行及关闭行为需开发时确定 |
| 核心板时钟/引脚 | 新查官方 52300 核心板图第 3 页：Y1100 为 50MHz，经 C1101 接 CLK / FPGA E2，可作为该版核心板的系统时钟依据，频率与 BLE 默认 CLK_HZ 一致；实际顶层连接、CST/SDC 和时序尚需适配。E8 为 S_READY、D7 为 S_DONE、D8 为 S_RECONFIGN，可据官方图补充原文专用脚说明，复用配置仍需核对 |
| 可制造性与信号质量 | 网表一致性不能代替 ERC/DRC、实际铜皮连通、USB 差分阻抗和时序检查 |

## 5. 需要用户回答的点

### 5.1 当前最需要回答

1. **除已确认的 BANK 全部改为 3.3V，实板还有哪些改料、补焊或飞线？** 重点是 C13/C14 是否仍各为 100nF、是否另补数字 VDD18 的 4.7µF。不清楚的项可注明“待查装配记录”。
2. **L1 实际装了什么值/物料号，RF1 与 RF2 实际装了哪一路？** 若用 RF2，还需说明是否已接外部天线。L1 不能从当前 `2.2nF` 标注确定正确电感值。

### 5.2 开始相应功能开发时再补

3. **具体屏模组及触摸/弹拨子板的资料在哪里？** 屏幕控制器、分辨率、SPI 已知；仍需采购链接或完整模组型号、FPC 引脚/接触面说明、初始化表，以及子板原理图/协议。若暂不调这些模块，可后补。
4. **蓝牙目标是演示测试还是传输实际业务数据？** 若做业务，需说明收发方向、数据类型/大致更新速率、是否长期运行，以及停止时希望只释放 I/O 还是断连并关闭射频。模块的具体规格资料可在适配时一起补充。

无需再回答已确认的阶段、所有 BANK 均为 3.3V、README 中的型号和分辨率，也不要求现在决定 USB 用途。芯片复位极性、内部稳压器电容要求、ULPI 输入门限由技术资料确认。
