# 可选 ACK_READ 下载扩展（0.2.2）

本扩展在原协议 v1 上增加可选命令 `0x35`，将“确认已经持久保存的上一块”和“读取下一块”合并成一次业务往返。原始协议快照不修改，原 READ / ACK / CLOSE / CANCEL 保留。需要新 FPGA 固件和 0.2.2 APP 配合才能加速；旧 APP 仍可按原流程下载，新 APP 遇到旧固件返回 UNSUPPORTED 时自动回退。

## 线格式与提交规则

采用原有 B1 分片、逻辑 CRC32、会话 nonce、request_id 和响应缓存，不新增 GATT 属性、UUID、能力位。Capability 仍为 flags=0x68、256 字节 PCM 块、窗口 1；MTU=23、UART 运行期921600/8E1。

`ACK_READ=0x35` 请求 payload 固定16字节，小端：

| 偏移 | 字段 | 长度 |
|---|---|---:|
| 0 | transfer_id | 4 |
| 4 | 下一块 offset，即上一块结束偏移 | 4 |
| 8 | 下一块 length，4..256且4字节对齐 | 2 |
| 10 | reserved，必须0 | 2 |
| 12 | 上一块 PCM CRC32 | 4 |

成功响应 opcode=0x35，payload 与 READ 成功响应相同：`transfer_id:u32, offset:u32, length:u16, reserved:u16=0`；对应 DATA 继续用0xD0、相同请求ID和原有28字节块头及PCM。响应中 offset 同时表示已确认的上一块结束偏移和本次读取起点。

必须先验证整个请求，才提交确认和分配下一块：有效且未过期的 transfer、没有尚待发送的 DATA、存在待确认的上一块、offset恰好等于其末尾、上一块CRC正确、下一块范围有效且在录音对象内。错误情况下不更新确认游标、不丢弃上一块。保留位/格式错误返回0x81，CRC/待确认状态冲突返回0x8D，下一块越界返回0x89，待发DATA返回0x82。

相同ID和完全相同请求使用原缓存重放相同响应和DATA；不再次提交ACK、不推进当前确认游标、不替换待确认块。更换ID重复上一条组合请求时，若已不对应当前待确认块，则拒绝为0x8D。不能用盲目重发新ID代替同ID重试。

第一块继续普通READ，末块仍发送普通ACK后CLOSE。EOF时不发送ACK_READ。取消、断线及30秒传输空闲超时释放传输引用；重新OPEN从手机持久检查点开始。

## APP 流程与兼容回退

APP 收到并验证块CRC后，先写PCM、同步持久检查点，才允许下一次ACK_READ承认这一块。界面“已持久保存”和“设备已确认”保持分开；组合请求成功后更新前一块确认偏移，末块独立ACK完成后更新最终确认。

新连接默认尝试可选命令。当设备明确返回0x80 UNSUPPORTED时，停用本连接的ACK_READ，依次执行原ACK和READ；这类错误没有提交确认，因此回退安全。CRC冲突、范围错误、超时等其他错误不转换成原ACK，以免掩盖协议问题。超时按原规则用相同ID、相同逻辑字节和新分片token重试，持续超时的ATT确认写入回退保留。

取消或断线发生在本地已保存、设备尚未确认时，持久检查点仍有效。恢复后重新OPEN请求该偏移，不需要回退或丢失已保存的块。

## 验证范围

RTL覆盖：无效下一块长度、错误上一块CRC、非法保留位不提交ACK；成功提交后读取下一块；相同ID响应及DATA精确重放；新ID的过时组合请求被拒绝；原ACK/READ、任务、CRC、EOF、CLOSE、取消重连保留。

APP单元测试覆盖：组合命令超时后字节/ID不变、旧固件仅探测一次并回退、CRC冲突不回退。实际BLE测试另主动丢弃执行后的完整响应，以验证设备已经提交ACK后的同ID恢复。

实板吞吐、完整音频、新旧组合兼容和Flash资格记录见 [本轮汇总](../reports/speed3_20261020/summary.json)。手机原生GATT、权限、UI及实际下载速度仍需用户安装APK验收。

## 已知启动标识限制

本轮同一镜像由 SRAM 切换到 Flash 并通过 JTAG 重载后，观察到 boot_id 重复，启动标识变化断言未通过；失败原始记录见 [检查结果](../reports/speed3_20261020/flash_boot_identity_repeat.json) 和 [限制说明](../reports/speed3_20261020/boot_identity_limitation.json)。使用 LE Rand 直接生成 boot_id 的初始化源码与上一轮相同，原因尚未完全定位。新镜像尚未做物理断电测试，不能据此承诺每次重启的身份唯一。

板卡重启或重配置后，应先删除手机未完成的下载，再开始新录音；本次通过的续传验收限于同一次启动内的取消及断线重连。完整录音 CRC、元数据和检查点前缀 CRC 校验仍保留。本项限制独立记录，不计入下载提速和普通重连通过项。
