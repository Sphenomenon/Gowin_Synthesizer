# 正点原子 800×480 参数来源

核对日期：2026-10-24。

- [官方产品页：4.3 寸 RGBLCD 电容触摸屏 800×480](https://www.openedv.com/docs/industry/4-lcd/4.3-RGBLCD-800480.html)。目标为并行 RGB 模块，不是另外销售的 MCU 接口 TFTLCD。
- 产品页链接的[官方资料包](https://pan.baidu.com/s/1fmOWUtUNOR1Pb6Zq_oG4HQ)，提取码 `6kig`。新版资料目录中《ATK-MD0430R模块用户手册_V1.1.pdf》（2025-08-11 修订）给出 ATK-MD0430R-800480 型号、5V 电源、3.3V IO、40 针定义。已通过公开预览读取印刷页 1、4、5、6，原理图页存为 `reference/atk-md0430r-manual-page4.jpg`。
- [正点原子官方 imx6ull-bareARM 驱动](https://github.com/alientek-openedv/imx6ull-bareARM/blob/master/21_adc/bsp/lcd/bsp_lcd.c)，`lcd_init()` 中 `lcdid == ATK4384` 分支明确设置 800×480、HSPW=48/HBPD=88/HFPD=40、VSPW=3/VBPD=32/VFPD=13，以及 `lcdclk_init(42,4,8)`，注释为 31.5MHz。`VDCTRL0` 配置 HSYNC/VSYNC 低有效、DE 高有效及上升沿采样。本工程采用这一完整驱动配置，扫描总计 976×528，刷新约 61.126Hz。
- 手册表 2.2.1.2 的典型值另列：像素时钟 30MHz（最高 50MHz），水平总计 928（范围 889–1143），垂直总计 525（范围 513–767），水平后沿 40/前沿 48、垂直后沿 32/前沿 13。它没有完整列出同步脉宽；不将该表的局部典型值与驱动参数混拼。选用官方驱动的 31.5MHz、976×528 在表列时钟及总周期范围内，仍需对实际模块版本实测。
- 本地 Gowin UG306-1.0.7E：138K PLL 的 VCO 范围 650–1300MHz；MDIV 支持 1/8 小数。设置 IDIV=FBDIV=1、MDIV=15+6/8、ODIV0=25，得到 VCO=787.5MHz、输出 31.5MHz。综合网表与 STA 均另行核对。

SDC 中 setup 5ns / hold 2ns 仍为暂定接口预算，以上手册预览未给出完整面板 setup/hold 电气规格；仿真和零时序违规不能替代排线、电源及面板实测。
