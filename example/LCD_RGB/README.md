## 时序及实现

采用[正点原子官方驱动的 ATK4384 分支](https://github.com/alientek-openedv/imx6ull-bareARM/blob/master/21_adc/bsp/lcd/bsp_lcd.c)。[参数来源](docs/参数来源.md)记录模块手册与驱动配置的区别。

| 参数 | 同步 | 后沿 | 有效区 | 前沿 | 总计 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 水平，像素时钟 | 48 | 88 | 800 | 40 | 976 |
| 垂直，行 | 3 | 32 | 480 | 13 | 528 |

- GW5AST-LV138PG484AC2/I1，50MHz 主时钟 V22，低有效重启 V13。
- PLL：50MHz ×(15+6/8) /25 = 31.5MHz，VCO=787.5MHz。输入及反馈分频均为 1；输出为 50% 占空比。
- 刷新率 31,500,000 /976 /528 ≈ 61.1261Hz，每帧约 16.3596ms。
- HSYNC/VSYNC 低有效，DE/背光高有效。RGB565 与控制信号在内部像素时钟上升沿寄存，PCLK 取反，使屏幕在另一半周期上升沿采样。PLL 锁定及外部重启共同控制复位，同步释放。
- 背光等待 3 个完整帧后开启，复位或失锁时关闭。未使用 PWM 调光。
- 扫描计数器按总周期收窄，坐标使用无符号数；启用输入/输出寄存器协同布局，满足更高像素时钟下的时序。
- IO 为板侧 3.3V LVCMOS、4mA。SDC 的 setup 5ns / hold 2ns 为暂定接口预算，尚不是面板电气规格签核。
- UserCode 为 `0x13802411`。独立工程，无 DDR/CPU/USB/音频依赖；保留 JTAG。

## 测试图案

自动循环，每种 360 帧，约 5.890 秒，只在帧边界切换。上电和复位从色条开始。需要静止观察时，将 `lcd_scan` 的 `FIXED_PATTERN` 设为对应编号后重新构建；默认 −1 为自动循环。

| 编号 | 图案 | 观察内容 |
| --- | --- | --- |
| 0 | 白、黄、青、绿、紫、红、蓝、黑色条 | 通道、色序与最大亮度 |
| 1 | 上红/中绿/下蓝渐变 | 5/6/5 位通道层次 |
| 2 | 黑白连续渐变 | 量化台阶与偏色；RGB565 无法提供真 24bit 灰阶 |
| 3 | 16 级灰阶 | 单调性、层次合并 |
| 4 | 暗部 0/8/16/24/32/40/48/56 | 暗部区分 |
| 5 | 亮部 199/207/215/223/231/239/247/255 | 高光区分 |
| 6 /7 /8 | 纯白 /纯黑 /约 50% 灰 | 坏点、漏光、均匀度 |
| 9 | 16×16 黑白棋盘 | 干扰、像素稳定性 |
| 10 | 16 根颜色数据线单独置 1 | 断线、短路、位权 |
| 11 | 1 像素白边框 +绿十字 | 首末行列、偏移及裁切 |

近黑/近白步长按 RGB565 选择，避免多个相邻 8bit 目标量化成相同输出。数值均为量化前目标，不能由这些图案直接测出物理对比度或色差。

## 复现

工作区根目录执行：

```sh
python3 example/LCD_RGB/tests/check_lcd.py
python3 example/RTL8723DS/tools/gowin_build.py example/LCD_RGB/build.tcl
python3 example/RTL8723DS/program_sram.py --manifest example/LCD_RGB/reports/last_build.json --check-only
```

`--check-only` 仅检查位流、SHA256、器件、UserCode 和时序，不访问下载器。构建沿用独立综合/PnR 进程、构建锁及 ASCII 暂存路径，成功产物按时间保存在 `builds/`，当前 manifest 为 `reports/last_build.json`。历史失败记录不等于当前状态。

仿真逐像素核对实际采样的 13 帧 800×480 输出，覆盖全部 12 图案及回绕；另测 48×24 固定白场、反向同步/背光极性。断言覆盖 976×528 扫描周期、同步脉宽、消隐为黑、3 帧背光延迟和有效区中途复位。顶层仿真检查端口色序、31.746ns PCLK 周期、采样前稳定时间、重启及 PLL 失锁/重锁路径。PLL 为行为桩，不能验证其模拟特性。
