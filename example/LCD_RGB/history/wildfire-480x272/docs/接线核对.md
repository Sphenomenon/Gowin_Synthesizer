## 正序与倒序

| 本板 FPC4 脚 | 本板功能 | 正序连接到参考 J19 | 完全倒序 n→41−n 时 |
| --- | --- | --- | --- |
| 1 | +5V | 1：5V | 40：CTP_SCL |
| 2 | +5V | 2：5V | 39：CTP_SDA |
| 3 | LCD_R0 / N22 | 3：3.3V | 38：CTP_INT |
| 4 | LCD_R1 / M22 | 4：3.3V | 37：CTP_RESET |
| 5 | LCD_R2 / M21 | 5：GND | 36：GND |
| 30 | PCLK / F18 | 30：DCLK | 11：R5 |
| 31 | HSYNC / E18 | 31：HSYNC | 10：R4 |
| 32 | VSYNC / C22 | 32：VSYNC | 9：R3 |
| 33 | DE / B22 | 33：DE | 8：R2（参考图接地） |
| 34 | BL / F21 | 34：DISP | 7：R1（参考图接地） |
| 35 | CTP_RST / E22 | 35：LCD_BL | 6：R0（参考图接地） |
| 36 | CTP_SDA / D22 | 36：GND | 5：GND |
| 38 | CTP_SCL / E21 | 38：CTP_INT | 3：3.3V |
| 39 | CTP_INT / D21 | 39：CTP_SDA | 2：5V |

**结论：针对上述官方参考针序，正序及倒序都不兼容。不要通过带电翻转排线试错。** 同向/反向描述接触面，实际 n→n 或 n→41−n 还取决于两个座子的触点方向、插入方向和各自 pin 1，需断电核对针 1 标记或通断。必须先取得实际屏幕版本针脚定义，才能决定是否需要转接。

## 色彩位权

本板可编程颜色线只占 FPC4 的 R0…R4、G0…G5、B0…B4；其余颜色线固定接地。若实际屏幕将它们当作 24bit 通道的最低位，最大输入仅 R=31、G=63、B=31，颜色和白场会明显受限。软件不能恢复被硬接地的高位。

RGB565 到正常 RGB888 屏应按有效位权连接：

| FPGA 逻辑数据 | 目标屏信号位权 |
| --- | --- |
| R[4:0] | R[7:3] |
| G[5:0] | G[7:2] |
| B[4:0] | B[7:3] |

屏幕低位可按手册接地或做位复制；电源、DISP、BL、触摸针位单独按实际版本核对。不可用 FPGA 数据 IO 为屏幕供电。当前 RTL 沿用本板网名，不代表已经完成转接。
