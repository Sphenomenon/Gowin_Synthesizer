# 138K 独立 RGB LCD 显示测试

目标：本版主板 FPC4 + 用户所述野火 4.3 inch / 480×272 / 24bit RGB 触摸屏。测试工程只生成显示图案，暂不驱动触摸控制器。

**当前为离线候选，未下载 SRAM、未写 Flash、未登记屏幕点亮。接线尚未确认：本板 FPC4 与已找到的野火官方开发板参考接口存在电源、色彩位权、背光和触摸针位差异；正反排线都不能直接认定兼容。** 详见 [接线核对](docs/接线核对.md)。该参考接口不等于已确认用户实际屏幕版本。

## 时序及实现

参数依据：[野火官方 4.3 inch TFT 教程](https://doc.embedfire.com/fpga/altera/ep4ce10_pro/zh/latest/code/tft.html)，表格 42-1 和 `tft_ctrl` 示例。

| 参数 | 同步 | 后沿 | 有效区 | 前沿 | 总计 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 水平，像素时钟 | 41 | 2 | 480 | 2 | 525 |
| 垂直，行 | 10 | 2 | 272 | 2 | 286 |

- GW5AST-LV138PG484AC2/I1，50MHz 主时钟 V22，低有效重启 V13。
- Gowin PLL：50MHz ×18 /100 = 9MHz，VCO=900MHz。参考输入/反馈分频均为 1。实际生成结果需以构建时钟报告核对。
- 刷新率 9,000,000 /525 /286 ≈ 59.9401Hz，每行约 58.333µs，每帧约 16.683ms。
- 默认同步脉冲为高有效，DE 高有效，背光高有效。同步极性可在 `lcd_scan` 参数中改。
- RGB565 与 HSYNC/VSYNC/DE 在内部像素时钟上升沿寄存；输出 PCLK 取反，屏幕在另一半周期的上升沿采样。PLL 锁定及外部重启共同控制复位，同步释放。
- 背光等待 3 个完整扫描帧后开启；复位/失锁关闭背光。未使用 PWM 自动调光。
- IO 采用板侧 3.3V LVCMOS、4mA。SDC 5ns setup /2ns hold 是初始接口预算，**不是未知屏幕版本的数据手册签核**。
- UserCode 候选 `0x13802410`。无 DDR/CPU/USB/音频依赖；JTAG 保留。

## 测试图案

自动循环，每种 360 帧，约 6.006 秒，只在帧边界切换。上电和复位从色条开始。需要静止观察时，将 `lcd_scan` 的 `FIXED_PATTERN` 设为对应编号后重新构建；默认 −1 为自动循环。

| 编号 | 图案 | 观察内容 |
| --- | --- | --- |
| 0 | 白、黄、青、绿、紫、红、蓝、黑色条 | 通道、色序与最大亮度 |
| 1 | 上红/中绿/下蓝渐变 | 5/6/5 位通道层次 |
| 2 | 黑白连续渐变 | 量化台阶与偏色；RGB565 无法提供真 24bit 灰阶 |
| 3 | 16 级灰阶 | 单调性、层次合并 |
| 4 | 暗部 0/8/16/24/32/40/48/56 | 暗部区分 |
| 5 | 亮部 199/207/215/223/231/239/247/255 | 高光区分 |
| 6 /7 /8 | 纯白 /纯黑 /约 50% 灰 | 坏点、漏光、均匀度 |
| 9 | 16×16 黑白棋盘 | 干扰、像素稳定性 |
| 10 | 16 根颜色数据线单独置 1 | 断线、短路、位权 |
| 11 | 1 像素白边框 +绿十字 | 首末行列、偏移及裁切 |

近黑/近白步长按 RGB565 选择，避免多个相邻 8bit 目标量化成相同输出。数值均为量化前目标，不能由这些图案直接测出物理对比度或色差。

## 复现

工作区根目录执行：

```sh
python3 example/LCD_RGB/tests/check_lcd.py
python3 example/RTL8723DS/tools/gowin_build.py example/LCD_RGB/build.tcl
```

构建沿用已有例程的独立综合/PnR 流程、构建锁、全新 ASCII 暂存路径、成功产物 SHA256 和 setup/hold 检查；保存到本目录 `builds/` 和 `reports/last_build.json`。现有成功版本不会被覆盖。`last_failure.json` 是某次历史失败，最终状态以相应时间的 manifest 为准。

仿真从实际输出的采样边沿解码 RGB565，逐像素检查 13 帧 480×272（涵盖全部 12 图案及回绕），另外检查固定白场/反同步极性/反背光极性。同步脉宽、525×286 扫描周期、消隐输出为黑、3 帧背光延迟、中途复位均有断言。图案 PNG 从真实 RTL 输出生成，保存在 `reports/`；`simulation.json` 记录检查数和源码哈希。数字仿真不模拟面板响应、PLL 模拟特性、排线或电源。

下载步骤暂不执行。确认实际屏幕针序及位权、电源/背光连接，再使用已有 SRAM 校验工具绑定成功 manifest 下载；Flash 固化不属于本轮测试。独立 LCD 镜像下载后会替换当前 SRAM 音频逻辑。
