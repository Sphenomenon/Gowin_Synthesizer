# P24 A/B/C 模式响度审计

P23 实体通过后，本阶段只校准 A/B/C 模式响度。原路径的模式差异位于 `unified_oscillator_engine.sv`：A、B、C 每声部分别装载 1、4、32 个 partial；增益 ROM 每个“模式×音色”行的系数和约为 32767。最终累加器对 A/B 固定除以 32，对 C 固定除以 4。这个 C 余量来自过去 4 声部实现，P14 恢复 32 声部后没有同步校准，因此相同累加值下 C 比 A/B 高 18.06 dB。

全局音量、expression、效果链、PT8211、声部分配和包络不区分模式，不是本轮根因。按当前活动声部数实时除法会在加减按键时造成音量抽动，本轮不采用。也没有改每种音色内部的 partial 比例，避免改变音色。

## 受控测量

P23 基线记录为 `results/p24_level_measure_20260916_175613_658924/measurement.json`。每次只发 MIDI 60、velocity 127，固定一种音色和模式，PCM 输入及效果关闭；跳过音符后的 1000 个最终 PCM 帧，再采 8192 帧左右声道。帧率为真实 48 kHz，模式、包络年龄、总音量和输出链一致。

基线未加权 RMS 中，B 相对 A 为 `−5.87…−0.08 dB`，C 为 `+8.48…+17.98 dB`。但 48 kHz 频谱按标准 A 权曲线加权后，B 相对 A 为 `−1.36…+2.95 dB(A)`，与用户“B 比 A 响”的听感一致；C 为 `+15.56…+17.98 dB(A)`。

第一次候选按未加权 RMS 对齐，记录为 `p24_level_measure_20260916_175955_090116`。它虽然把数字 RMS 对齐到接近 0 dB，却把 B/C 的 A 计权结果放大到 `0…+8.54 dB(A)`，并增加最坏同音叠加峰值，因此被明确否决且未构建位流、未下载。

最终系数在 `rtl/audio/p24_mode_gain_scale.json`。A 保持 Q16 unity，B/C 每个音色使用固定行系数，使 A 计权能量匹配对应 A 音色。系数只在构建新结果目录时缩放冻结增益 ROM，原结果与原 ROM 不修改。每行统一缩放，所以音色内部谐波比例保持不变；每个新声部装载自己的系数，活动声部变化不会改变已有声部。

C 钢琴若完全按 A 计权对齐，32 同音极限出现 14 个饱和帧。最终将该行再降低 0.372 dB，使单音峰值与 A 钢琴一致；其它十四组保持 A 计权目标。最终单音 B/C 的 A 计权误差除 C 钢琴外均在 `−0.0012…+0.0017 dB`，C 钢琴为 `−0.372 dB`。所有单音、十五组 32 音跨音高和弦，以及 A 弦乐/B 马林巴/C 钢琴三个最高峰 32 同音极限均无饱和和效果链 clip。

A 计权是可重复的数字听觉近似，不等于实体耳机上的主观响度结论。最终仍需在相同音符、力度、音色、总音量和效果关闭条件下逐项切换 A/B/C，再回归效果开启及正常演奏。

本轮没有改变时钟域、事件队列或背压：控制事件仍在 76.8 MHz 音频域提交，输出仍为 48 kHz；Push 48 MHz、CPU 50/100 MHz、HDMI、DDR 和状态快照路径不变。P23 PANIC、Push pad held、连续压力及 32 声部分配保持原样。USB IN error 诊断仍为 `null`，完整 routed audit 仍保留 `effect_mask_sync_[0..2]_s0/RESET` 三个旧缺口。
