# 总体音量与 L/R 平衡

2026-09-09 起，输出链路改为：**各声部按自身包络和力度生成完整幅度 → 40 位直接相加 → 总体音量 → L/R 平衡 → 饱和及 PCM16 舍入 → PT8211**。不再按总槽数或活动声部数自动除法。

单声部设置满幅包络、100% 力度、总体音量100%时，可以达到输出满量程；不会只占1/32。原音色预设仍保留各自力度。多个声部相加超过满量程时最终会饱和，可用总体音量保留余量：例如两个满幅同相声部，总音量25%时应输出半幅，而不是先削顶再得到四分之一幅。32个同相满幅声部，总音量3.125%可输出满幅。

## 操作与协议

GUI增加独立的总体音量0–100%和L/R平衡滑块，以及平衡回中按钮。总体音量默认100%、平衡默认居中；屏幕区分本地目标与ACK已确认的状态。连接/重连先清音并同步输出设置；旧位流不支持新命令时禁用相应输出控制，保留演奏连接。连续拖动合并过期请求，不逐次阻塞等待ACK。

| 命令 | voice | value |
|---|---|---|
| `10 MASTER_VOLUME` | `FF` | 无符号Q0.31，`00000000`静音、`80000000`单位增益 |
| `11 LR_BALANCE` | `FF` | `00000000`全左、`40000000`居中、`80000000`全右 |

两者允许范围均为0…`80000000`，flags必须0。非法voice返回2，非法范围/flags返回3，目标值保持。命令在帧起点提交；PANIC清除发声，不重置输出设置；硬件复位恢复默认值。CLI用法和主机操作见[GUI说明](gui_control.md)及[协议](uart_protocol.md)。

居中时两路均为单位平衡增益；向左移动时左路保持单位增益、右路线性下降，向右反之。这是全局左右平衡，不是逐声部声像，也没有在中心额外衰减3dB。

## 平滑与数值

总体音量和平衡目标均在每个采样帧向目标移动最多`0x00800000`，完整范围最长256帧/**5.24288ms**，中心到最左/右128帧。新目标从当前值继续移动。整个声音帧的所有声部标签及最终混音使用同一组平滑增益；命令在帧内到达不会把两套增益拼进同一双槽PCM。

独立输出级共用一个40×33位有符号乘法器，乘法结果保留73位，除以`2^31`向负无穷取整，仍保留40位混音范围。先乘总体音量，再分别乘左右平衡，最后才饱和到Q1.31。PT8211按最近值、半值远离零规则转换为PCM16；两个声道作为一对缓存和发送。欠载同时补零并清除有效声音标签。

声部核心仍每帧225个50MHz时钟，引擎输出226周期；顶层最终音量级样本事件为帧开始后**234周期/4.68µs**，不增加一个音频采样帧的延迟。仍在每1024周期的下一DAC装载前完成。

## 显示与延迟观测

FFT、结像、左右峰值和M波形继续从实际最终PT8211串行引脚解码，因此反映总体音量和平衡后的PCM。居中时当前单声道音源显示居中竖线；偏向左/右时结像相应倾斜，完全偏向一侧时另一频谱和峰值归零。MID-SIDE结像的全左/全右是相对竖直中轴的±45°，水平线表示等幅反相，详见[坐标说明](output_analysis.md#结像场与电平)。功放、DAC模拟部分及耳机响应不在数字观察范围。

输出级同时计算每个声部经过本帧总体音量后，是否在至少一个声道跨过PCM16非零阈值；平衡增益最大的一侧始终为1，因此不会把总体静音或过小的独立贡献误标为起音。此标签衡量独立贡献，声部间抵消仍可能使最终混音为零。

`0E`全链路记录也接受10/11为新的声音命令，记录新目标版本的首个输出样本和双槽发送完成，不把这当作滑块渐变完成；它们不产生NOTE_ON专有字段。`0F`仍只由同声部NOTE_ON替换起点，总体静音时尚未有效的音符保持等待，解除静音后可首次满足贡献阈值。HOLD波形在音量/平衡命令变更版本后重新捕获。

## 验证

独立80位整数模型验证输出级1336帧，包括32声部正负宽位混音、先降音量再饱和、分数增益、两路平衡、静音/渐变、帧内目标变化和标签。实际32声部引擎→音量级→PT8211→观察器验证1613个串行帧，覆盖满幅单音、双声部25%输出、全左/全右/中间位置、静音、非法命令、234周期计算、PANIC及零欠载。另有立体声串行边界测试、主机滑块/重连/旧固件和完整回归。最终构建、日志及板测边界见[验证记录](verification.md)。
