# 手机本地／A2DP播放与25K MIDI：demo-d3

日期：2026-11-01（Asia/Shanghai）。版本 `0.3.1-demo-d3`，versionCode16。只修改 Android，未修改或部署25K／138K固件。此阶段主线程按新方向推进 W headless A2DP→D实时效果→DAC，保留USB Host／25K；W HDMI／分析／录音／下载暂停。历史demo-d1/d2及独立25K录音业务的既有证据不受此记录替代。

## 实际契约与限制

核对25K维护源码 `projects/25k/example/MIDI_KEYBOARD/config/ble_midi.json`、`rtl/ble_board/midi_ble_gatt.v`、`rtl/transport/ble_midi_codec.v` 及 `rtl/instrument/midi_keyboard_application.v`。服务 UUID `03B80E5A-EDE8-4B33-A751-6CE34EC4C700`、MIDI特征 `7772E5DB-3868-4112-A1A9-F2669D106BF3`，Read／Write Without Response／Notify，ATT MTU23。现有接收器只接受单值单事件、无running status、无SysEx；本App每次无响应写入一个5字节值：BLE时间戳头2字节＋完整3字节Note On／Off／CC。CCCD启用后才提供25K定义的online条件；不要求更大MTU、不使用无关的工作站录音业务服务。

`midi_keyboard_application.v` 的 `host_valid`／`remote_ble` 路径把主机输入用于16键灯光；README也明确不自动回送或本地发声。本轮没有BLE→USB转发。因此“手机→25K控制”的准确范围是既有BLE MIDI接收／反馈路径，**不能声称手机键盘已经25K驱动138K发声**。设备端仍须补齐转发、防回环和射频断线的实际停音策略。

## 实现

- 手机键盘音符48..63，力度1..127及通道1..16；按下发Note On，释放／手势取消发Note Off。重复按下同一键不重复入队，通道改变先清理旧音符。
- 数据层64项有界队列，每个会话有代际身份。PANIC丢弃未发送旧按键，逐个发送16通道的CC120／CC123；切页／后台发PANIC。正常断开先清理再关闭，异常断开清本地持键，重连先清理再开放新按键。队列满或发送失败关闭连接并提示核对设备已停音。写入成功只表示Android GATT操作完成，无设备应用ACK。
- 系统SAF读取音频；异步准备、播放／暂停／定位。明确选择手机扬声器、已连接耳机或具体A2DP设备，用实际产品名显示设备。`setPreferredDevice`仅为请求；以`routedDevice.id`等于所选且仍存在的输出为确认。初始两秒未形成对应实际路由则暂停，已确认后改变立即暂停；设备移除、焦点丢失或应用后台也暂停。
- 手机音频、25K MIDI和既有BLE业务服务独立。没有本地MIDI合成器、USB手机接收路径或新设备协议；保留app→data→ble→protocol依赖方向。没有新增媒体库、麦克风或全部文件权限。
